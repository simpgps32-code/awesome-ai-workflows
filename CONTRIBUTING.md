# Contributing to Awesome AI Workflows

Thank you for your interest in contributing to **Awesome AI Workflows**! 🎉

Our mission is to collect and maintain **practical, actionable, and human-verified AI workflows** that solve real business, technical, and creative challenges.

Unlike directory lists that only compile single AI tools, **every workflow here must be an executable pipeline** with:
1. Clear Target Audience & Goal
2. Proven Toolchain (Commercial or Open-Source)
3. 4-Step Actionable Checklist (SOP)
4. Ready-to-Use Copy-Paste Prompt Template

---

## How to Submit a New Workflow

1. **Check Existing Workflows**:
   - Search [README.md](./README.md) or visit [https://aizenme.com/](https://aizenme.com/) to make sure the workflow isn't already covered.

2. **Fork the Repository**:
   - Fork this repository and create a new branch: `git checkout -b add-my-workflow`.

3. **Follow the Standard Format**:
   ```markdown
   ### [Workflow Title (English / 中文)]
   - **Category**: Video / Design / Audio / Coding / Writing / Research / Automation
   - **Tools Used**: Tool A, Tool B, Tool C
   - **Target Audience**: Who is this best for?
   - **Execution SOP**:
     1. Step 1: Preparation & tool setup
     2. Step 2: Prompt execution & generation
     3. Step 3: Polishing & quality check
     4. Step 4: Final export & distribution
   - **Prompt Template**:
     ```
     [Copy-ready prompt template with placeholders]
     ```
   - **Verified Website / Source**: [Link to tool or guide]
   ```

4. **Submit a Pull Request**:
   - Submit your PR with a concise description of how you verified this workflow in a real-world scenario.

---

## Criteria for Inclusion

- ✅ **Actionable**: Must contain concrete execution steps, not vague advice.
- ✅ **Tested**: The prompt and tools must actually work without hallucination or broken dependencies.
- ✅ **Tool Combinations**: Preference for multi-tool synergy (e.g. `Whisper + DeepSeek`, `ComfyUI + ControlNet`, `Cursor + Supabase`).
- ❌ **No Pure Self-Promotion**: Commercial tools are welcome, but only if they represent the best current solution for that specific step.

Thank you for helping everyone turn ideas into real-world AI outcomes!
