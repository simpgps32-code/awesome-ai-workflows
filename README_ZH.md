## 💡 为什么创建这个项目？

网络上充斥着堆砌上万个 AI 工具的所谓“导航站”，但遇到具体业务问题时依然不知道“到底怎么选工具、怎么写提示词、具体第几步该做什么”。**Awesome AI Workflows** 专注于：
- **拒绝工具罗列**：每个方案对应一个真实业务痛点（做产品视频、跑财务对账、排查安全漏洞、搭建私有会议纪要等）。
- **实战提示词**：所有提示词均在 DeepSeek V3/R1、Claude 3.7、GPT-4o 实测通过，拒绝口语化废话。
- **4 步执行清单**：从输入准备、AI 提炼、人工校验到终极交付的闭环标准流程。
- **代码驱动动效**：每个方案在 [aizenme.com](https://aizenme.com) 均配有纯代码渲染的交互动效，直观呈现流程。
- **重度覆盖本地离线方案**：深入挖掘 Ollama、FunASR、Whisper、ComfyUI、Docker 等 100% 保护企业隐私的自托管方案。
